# 来源与内容边界

本项目的书影音资料由编辑整理。作品的出版/上映年份、创作者、作品名称应在更新时参考出版机构、发行方、IMDb、出版社官网或公开书目信息核对。条目中的「为什么看、核心收获、看完怎么用、别学偏了」是原创编辑观点和练习建议，不宣称作品创作者本来就意图讲述这些理论。

## 关键边界
- INTJ 属于人格类型分类工具的常见代码，不是人的能力、人格优劣或命运证明。
- 不应给电影角色贴确定 MBTI 类型标签，也不建议用 MBTI 代替专业的心理评估。
- 虚构影视情节不提供管理、商业、心理学结论的实证证据。剧集里的行为可能不值得模仿。
- 影视海报、原著大段文本、付费电影与电子书不在此项目分发。
- 某些作品可能含成瘾、暴力、心理困扰、家庭冲突等情节，具体内容提醒以条目 warning 字段为准。

## 维护规则
PR 请附作品官方页面或出版信息来源，并清楚区分作品事实与读者解读。纠错优先于扩张清单，数量并非目标。
