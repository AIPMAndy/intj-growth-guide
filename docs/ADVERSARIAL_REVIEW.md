# 反方审核

## 人格类型决定论
风险：把 INTJ 看成比其他人格更聪明/更适合管理。处理：网站只用它作为阅读主题标签，不把人格标签用于能力预测。

## 把剧本当管理学
风险：只学到主角「赢」的姿态，忽视现实团队、制度与他人感受。处理：每条都要求填写别学偏了。

## 收藏代替行动
风险：攒一堆书影音推荐，现实行为没有改变。处理：7/30 天行动路线+本地任务勾选+笔记。

## 版权与外链
风险：盗链海报、盗版电影/电子书。处理：只提供作品识别信息和原创摘要，没有分发受保护内容。

## 引导转化
风险：自媒体商业入口盖过用户价值。处理：内容免费、搜索阅读不受阻；咨询和微信入口可选，不收集浏览行为。
