# 内容来源、事实边界与反方审查

**项目性质：** 书影音的主题推荐、情节理解与训练建议属于编辑性判断。内容不会把角色硬判为 INTJ，也不会宣称某部电影 / 某本书能因果地提高工资。推荐动作是可测试的职场练习，不是获得晋升的保证。

## 选片标准

1. 作品真实存在，并提供中英文名称方便读者核查不同地区译名。
2. 能指向一个具体职场情境（价值、业绩、协作、管理、组织决策、谈判）。
3. 明确一条可迁移的观察原则和一个当天或当周能落地的动作。
4. 写出至少一个“别学偏了”的反面提醒，尤其避免模仿犯罪、操纵、霸凌和违法行为。
5. 对存在戏剧改编、争议或高度行业专属性的情节作局限说明。

- 作品信息：建议按英文原名核对出版社、作者或出品方的正式资料；同一书可能存在多种简体中文译名。本项目初版未逐条提供出版社 ISBN / 剧集官方条目，所以不要把编辑性解读当逐条独立核实的事实结论。

**警惕：** 作品不是职场能力测验；影视人物不代表整个群体。职业结果同时受组织资源、行业、宏观经济、歧视、地域、机会、薪酬制度与个人选择影响。因果推断必须有相应证据，个人体验不等于普遍规律。
