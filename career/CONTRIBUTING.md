# 如何为专题贡献内容

感谢一起共建。欢迎纠正书名、英文原名、内容误读、错别字和失效链接，也欢迎提交值得收录的新作品。

1. 先在 [Issues](https://github.com/AIPMAndy/intj-growth-guide/issues) 描述要修正的问题，确认不与现有作品重复。
2. 作品条目填写 `id / kind / title / original / track / why / principle / action / trap` 九个字段。
3. `kind` 只能是 `film`（电影）、`series`（剧集）或 `book`（书籍）。
4. `track` 只能是：市场定位、业绩证明、沟通影响、晋升带队、组织博弈、谈薪跳槽。
5. 说明作品为什么能帮助读者解决一个具体问题，提供现实可验证动作，并明确不应照搬的风险。
6. 提交 PR 前运行 `python3 -m unittest discover -s tests -v`，保持事实、名称与数据一致。

**不接受：** 盗版内容、虚构的真实客户成果、未经授权的同事或客户个人信息、宣传夸张的加薪成功率、用 MBTI 标签直接判定他人能力的内容。

书影名称、官方出版资料和作者应核查；书籍不同中文版可能有不同译名，请同时给出英文原名和参考版本。新增条目时，需要同步更新网站与测试中的总数及各分类数量。

编辑原则请看 [资料来源与局限](docs/SOURCES.md)。
